# PatriaSoul Content Engine

## Tijek rada

1. Urednik zada temu.
2. Sustav pripremi sveobuhvatan članak i stavlja ga u status **ZA PROVJERU**.
3. Članak se pregledava na **Uredničkom pregledu**.
4. Nakon pregleda koristi se **ODОBRI I OBJAVI**.
5. Objavu izvršava GitHub Actions, a ne JavaScript u pregledniku.

## Opseg

Standardni članak mora imati najmanje **1.500 riječi** i više smislenih cjelina. Kraći tekstovi dopušteni su samo ako ih urednik izričito označi kao poseban format.

## Autor

Autor svih članaka je **PatriaSoul**.

**Čuvari nasljeđa** je format/kategorija i nikada nije autor.
